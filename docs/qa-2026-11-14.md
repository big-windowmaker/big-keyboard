# Relatório de testes — 0.1.0 (2026-11-14)

Ambiente: Manjaro, kernel 6.18, GTK 3.24. "Wayland" = wlmaker aninhado
(backend X11, renderizador pixman, sessão D-Bus própria); "X11" = Xvfb com
Window Maker. Ambos sem tocar na sessão gráfica real. O controle "virtual"
é um gamepad uinput (`tests/` e roteiros de laboratório) — o mesmo caminho de
um controle real (udev marca `ID_INPUT_JOYSTICK`, ACL `uaccess`).
